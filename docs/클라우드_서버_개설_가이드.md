# GroupK 근태앱 — 클라우드 서버 개설 단계별 가이드

- 작성일: 2026-11-14
- 기준 서비스: **AWS Lightsail (서울 리전)**. 월 고정 요금이고, 고정 IP·방화벽 화면이 단순해서 비전문가가 운영하기 쉽습니다.
- 소요 시간: 약 1시간. 도메인 DNS 반영 대기시간은 별도입니다.
- 준비물: 법인카드(해외결제 가능), 휴대폰(본인인증), 회사 도메인 관리 계정(가비아 등)

|---|---|---|---|

## 1단계. AWS 계정 만들기

1. https://aws.amazon.com/ko → **AWS 계정 생성**
2. 이메일: 개인 메일보다 **회사 공용 메일**(예: admin@회사도메인)을 권장합니다. 담당자가 바뀌어도 계정을 잃지 않습니다.
3. 계정 유형은 **비즈니스**를 선택하고 사업자 정보를 입력합니다.
4. 결제 카드를 등록합니다. 1달러 승인 테스트 후 취소됩니다.
5. 휴대폰 본인인증을 하고, 지원 플랜은 **기본(무료)** 을 선택합니다.
6. 가입이 끝나면 **루트 계정에 MFA(2단계 인증)** 를 즉시 설정합니다(8단계 참고).

## 2단계. 서버 만들기

1. AWS 콘솔 상단 검색창에서 **Lightsail**로 이동합니다.
2. **인스턴스 생성(Create instance)** 을 누릅니다.
3. 아래 표대로 설정합니다.

| 항목 | 선택 |
|---|---|
| 리전 | **서울 (ap-northeast-2)**, 가용 영역 a |
| 플랫폼 | **Linux/Unix** |
| 블루프린트 | **운영 체제(OS 전용) → Ubuntu 24.04 LTS** |
| 네트워크 유형 | **듀얼 스택(IPv4+IPv6)**. IPv6 전용은 국내 통신망에서 접속이 안 될 수 있습니다. |
| 요금제 | **메모리 1GB 플랜** 권장(40명에 충분). 여유를 원하면 2GB |
| 인스턴스 이름 | `groupk-hr` |

4. **인스턴스 생성**을 누르고 1~2분 기다리면 상태가 '실행 중'으로 바뀝니다.

> 요금: 플랜별 월 요금은 수시로 바뀌므로, 선택 화면에 표시되는 금액이나 공식 요금 페이지(서울 리전)를 확인하세요. 1GB 플랜은 월 10달러 미만대로 알려져 있으나 **확인 필요**입니다. 서버를 꺼 두어도 요금은 청구됩니다.

## 3단계. 고정 IP 붙이기

서버를 재시작하면 IP가 바뀝니다. 고정 IP를 붙여야 도메인 연결이 유지됩니다.

1. Lightsail → **네트워킹** 탭 → **고정 IP 생성**
2. 리전은 서울, 연결할 인스턴스는 `groupk-hr`, 이름은 `groupk-hr-ip`로 정합니다.
3. 생성된 IP(예: `3.38.xxx.xxx`)를 메모합니다.

> 인스턴스에 연결된 고정 IP는 추가 요금이 없습니다. 반대로 **연결하지 않은 채 두면 과금**됩니다. 서버를 삭제할 때는 고정 IP도 함께 해제하세요.

## 4단계. 방화벽에 HTTPS 열기

Lightsail은 기본으로 22(SSH)와 80(HTTP)만 열려 있습니다. **이 단계를 빠뜨리면 접속이 되지 않습니다.**

1. 인스턴스 `groupk-hr` → **네트워킹** 탭 → IPv4 방화벽 → **규칙 추가**
2. 애플리케이션 **HTTPS**를 고르면 TCP 443이 자동으로 채워집니다. 저장합니다.
3. IPv6 방화벽에도 HTTPS 규칙을 똑같이 추가합니다.

결과는 SSH(22), HTTP(80), HTTPS(443) 세 개입니다.

## 5단계. 도메인 연결

### 회사 도메인이 이미 있는 경우 (권장)

예를 들어 `groupk.co.kr`이 가비아에 있다면 다음과 같이 합니다.

1. 가비아 → My가비아 → **DNS 관리툴** → 해당 도메인 **설정**
2. **레코드 추가**: 아래 표대로 입력하고 저장합니다.

| 타입 | 호스트 | 값/위치 | TTL |
|---|---|---|---|
| A | `hr` | 3단계의 고정 IP | 600 |

3. 결과적으로 `hr.groupk.co.kr`이 근태앱 주소가 됩니다.
4. 반영에는 보통 10분~1시간 걸립니다. 확인 방법은 아래 중 하나입니다.
   - 내 PC 명령 프롬프트에서 `nslookup hr.groupk.co.kr` 실행 → 고정 IP가 나오면 완료
   - https://dnschecker.org 에서 도메인 조회

> 홈페이지를 외부 업체가 관리하고 있다면, 그 업체에 위 A레코드 한 줄 추가를 요청하면 됩니다. 기존 홈페이지에는 영향이 없습니다.

### 도메인이 없는 경우

가비아·후이즈 등에서 `.co.kr` 또는 `.com`을 구입합니다(연 2만 원 내외, 업체별 확인 필요). 이후 위와 같이 A레코드를 추가합니다.

## 6단계. 앱 설치

1. Lightsail → 인스턴스 `groupk-hr` → **SSH를 사용하여 연결** 버튼을 누릅니다. 브라우저에 검은 터미널 창이 열립니다.
2. 아래 명령을 **순서대로 하나씩** 복사·붙여넣기 합니다.

**(1) 앱 코드 받기**

저장소가 **공개(public)** 인 경우:

```bash
sudo git clone https://github.com/ksb8390-bit/groupk01.git /opt/groupk
```

저장소가 **비공개(private)** 인 경우에는 GitHub → Settings → Developer settings → **Fine-grained personal access token**을 만듭니다. 대상 저장소는 groupk01만, 권한은 Contents: Read-only로 제한합니다. 그런 다음 아래 명령을 실행하고, 비밀번호를 물으면 토큰을 붙여넣습니다.

```bash
sudo git clone https://ksb8390-bit@github.com/ksb8390-bit/groupk01.git /opt/groupk
```

**(2) 운영 브랜치 선택** — 코드가 main 브랜치에 합쳐지기 전이라면 작업 브랜치로 전환합니다.

```bash
cd /opt/groupk && sudo git checkout claude/jolly-rubin-a0y1dk
```

**(3) 자동 설치 실행** — 도메인 부분을 실제 주소로 바꿉니다.

```bash
sudo bash /opt/groupk/deploy/setup_server.sh hr.groupk.co.kr
```

설치 스크립트(`deploy/setup_server.sh`)가 하는 일:

| 순서 | 내용 |
|---|---|
| 1 | 서버 시간대를 한국시간(KST)으로 설정 |
| 2 | Python, SQLite, Caddy(HTTPS 자동 인증서) 설치 |
| 3 | 스왑 메모리 1GB (작은 서버 안정화) |
| 4 | 전용 실행 계정 `groupk` 생성, 가상환경·패키지 설치 |
| 5 | 앱을 시스템 서비스로 등록(재부팅 시 자동 시작, 장애 시 자동 재시작) |
| 6 | 도메인에 대한 HTTPS 인증서 자동 발급·갱신 |
| 7 | 서버 방화벽(ufw) 22·80·443만 허용 |
| 8 | 매일 03:00 DB 백업, 30일 보관 |

마지막에 `앱 서비스: 실행 중`, `앱 응답: 정상`이 나오면 성공입니다.

## 7단계. 관리자 계정 생성·접속 확인

**(1) 관리자 계정 생성** — 아이디, 이름, 입사일, 비밀번호를 차례로 입력합니다.

```bash
sudo -u groupk HR_DATABASE=/opt/groupk/instance/hr.sqlite3 /opt/groupk/.venv/bin/flask --app hr.app create-admin
```

**(2) 접속 확인**

1. PC 브라우저에서 `https://hr.groupk.co.kr`에 접속합니다. 주소창 자물쇠 표시를 확인하세요.
2. 관리자로 로그인한 뒤 **설정 → 근무지**로 갑니다. 사무실에서 휴대폰으로 접속해 **현재위치** 버튼을 누르면 본사 좌표가 입력됩니다.
3. 휴대폰을 홈 화면에 추가한 뒤 테스트 출근 → 퇴근을 해 봅니다. **현황** 화면에 반영되는지 확인합니다.
4. 테스트 기록은 **월간근태 → 직원 → ✎**에서 출퇴근 칸을 비우고 저장하면 삭제됩니다.

## 8단계. 보안·백업 마무리

| 항목 | 방법 | 중요도 |
|---|---|---|
| AWS 루트 계정 MFA | 콘솔 우측 상단 계정명 → 보안 자격 증명 → MFA 할당 (Google Authenticator 등) | 필수 |
| 결제 알림 | 결제 및 비용 관리 → 예산 → 월 예산 1~2만 원 상당 초과 시 메일 | 권장 |
| 서버 스냅샷 | Lightsail 인스턴스 → **스냅샷** 탭 → **자동 스냅샷 활성화** (매일 서버 전체 백업, 소액 과금 — 확인 필요) | 권장 |
| DB 백업 외부 보관 | 월 1회 `/var/backups/groupk-hr/` 최신 파일을 내려받아 회사 NAS·드라이브에 보관 | 권장 |
| SSH 접속 | Lightsail 브라우저 SSH만 사용(비밀번호 로그인 기본 차단 상태 유지) | 유지 |

## 운영 중 자주 쓰는 명령

모두 Lightsail 브라우저 SSH 창에서 실행합니다.

**앱 상태 확인**

```bash
sudo systemctl status groupk-hr --no-pager
```

**앱 오류 로그 보기**

```bash
sudo journalctl -u groupk-hr -n 50 --no-pager
```

**HTTPS 인증서 문제 확인**

```bash
sudo journalctl -u caddy -n 50 --no-pager
```

**앱 업데이트** — 새 기능이 저장소에 올라온 뒤 실행합니다.

```bash
cd /opt/groupk && sudo git pull && sudo bash deploy/setup_server.sh hr.groupk.co.kr
```

**관리자 비밀번호 분실 시** — 새 관리자 계정을 하나 더 만든 뒤 기존 계정의 비밀번호를 초기화합니다.

```bash
sudo -u groupk HR_DATABASE=/opt/groupk/instance/hr.sqlite3 /opt/groupk/.venv/bin/flask --app hr.app create-admin
```

**백업에서 복구** — 날짜 부분을 바꿔서 실행합니다.

```bash
sudo systemctl stop groupk-hr && sudo -u groupk cp /var/backups/groupk-hr/hr-2026-11-20.sqlite3 /opt/groupk/instance/hr.sqlite3 && sudo systemctl start groupk-hr
```

## 문제 해결

| 증상 | 원인 | 조치 |
|---|---|---|
| 사이트가 열리지 않음(시간 초과) | 4단계 443 포트 미개방 | Lightsail 네트워킹 탭에서 HTTPS 규칙 추가 |
| "안전하지 않은 사이트" 경고 | DNS 미반영 상태에서 인증서 발급 실패 | `nslookup`으로 IP 확인 후 `sudo systemctl restart caddy` |
| 502 Bad Gateway | 앱 서비스 중지 | `sudo systemctl restart groupk-hr`, 로그 확인 |
| 휴대폰에서 위치가 안 잡힘 | 브라우저 위치 권한 거부 / 위치수집 미동의 | 휴대폰 설정 → 브라우저(Safari/Chrome) 위치 허용, 앱에서 동의 |
| 출근 시각이 9시간 다르게 보임 | 해당 없음(앱은 KST 고정) | 발생 시 개발 담당에게 문의 |

## 비용 요약 (가정치 — 견적·공식 요금 확인 필요)

| 항목 | 금액(추정) | 주기 |
|---|---|---|
| Lightsail 1GB 플랜 (서울) | 월 1만 원 내외 | 월 |
| 자동 스냅샷 | 월 1~2천 원 수준 | 월 |
| 도메인 (신규 구입 시) | 2만 원 내외 | 연 |
| 고정 IP (인스턴스 연결 시) | 0원 | — |

환율과 리전별 요금에 따라 달라집니다. 결제는 달러로 이뤄지며 해외결제 수수료가 붙을 수 있습니다.

## 확인 필요 사항
1. Lightsail 서울 리전 1GB 플랜의 현재 월 요금 — 인스턴스 생성 화면에서 확인
2. GitHub 저장소 공개/비공개 여부 — 비공개라면 6단계 토큰 방식 사용
3. 회사 도메인 보유 여부와 DNS 관리 주체(직접 / 홈페이지 업체)
4. 운영 전 작업 브랜치를 main에 병합할지 여부

## 가정 사항
- AWS Lightsail을 기준으로 작성했습니다. 네이버클라우드 등 국내 업체를 써도 Ubuntu 서버만 있으면 6단계 이후는 동일합니다.
- 근태 데이터는 서울 리전(국내)에 저장됩니다.
