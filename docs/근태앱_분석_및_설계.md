## 4. 적용 규칙과 근거

근거 위계: 법령 → 회사 규정(취업규칙) → 실무 설정. 조문은 기억 기반 인용이며 **최신 개정 여부 미확인 — 국가법령정보센터 확인 필요**.

| 규칙 | 앱 구현 | 근거 |
|---|---|---|
| 법정근로시간 | 주 40h 기준 표시 | 근로기준법 제50조 |
| 연장근로 한도 | 주 52h 초과 ⚠ 경고 (48h 초과 주의) | 근로기준법 제53조 ① |
| 휴게시간 | 근로시간 산정 시 설정값(기본 60분) 공제 | 근로기준법 제54조 |
| 연차 — 1년 미만 | 1개월 개근 시 1일, 최대 11일 (입사 1주년 전일까지) | 근로기준법 제60조 ② |
| 연차 — 1년 이상 | 15일 | 근로기준법 제60조 ① |
| 연차 — 가산 | 3년 이상 근속 시 최초 1년 초과 매 2년 1일, 한도 25일 | 근로기준법 제60조 ④ |
| 지각 판정 | 소정 출근시각 + **10분 초과** 시 지각 (회사 결정, 2026-11-14) | 취업규칙 — 법정 기준 없음 |
| 휴일근무 → 대체휴가 | 토·일·등록 휴일 근무 신청 → 승인 시 대체휴가 적립(종일 1일 / 반일 0.5일 × 배율), 평일에 '대체휴가'로 사용. 연차와 별도 관리 | 아래 '대체휴가 운영 시 법적 유의사항' 참고 |
| 연차 사용촉진 | 미구현 — 서면 촉진 절차 결과를 '조정'으로 반영 | 근로기준법 제61조 |
| 서류 보존 | DB에 영구 보관(삭제 기능 없음, 관리자 수정은 이력화) | 근로기준법 제42조(3년 보존) — 근태기록 해당 범위 **확인 필요** |

**자동 판정하지 않는 사항(관리자 '연차 조정'으로 반영)**
- 출근율 80% 미달, 1년 미만자 미개근 월
- 회계연도(1.1.) 기준으로 일괄 운영하는 경우의 비례 부여·퇴직 시 정산
- 이월, 사용촉진에 따른 소멸

> 결정(2026-11-14): 연차는 **입사일 기준**으로 운영한다.

### 대체휴가 운영 시 법적 유의사항

휴일근무 후 평일에 쉬게 하는 방식은 법적으로 두 가지로 나뉘며, 요건과 부여 일수가 다르다. 앱의 **설정 → 대체휴가 적립 배율**로 선택한다.

| 구분 | 휴일대체 (배율 1.0) | 보상휴가제 (배율 1.5) |
|---|---|---|
| 근거 | 근로기준법 제55조 ② 단서 | 근로기준법 제57조 |
| 성격 | 휴일을 **사전에** 다른 근로일과 맞바꿈 → 원래 휴일 근무는 통상 근로가 됨 | 휴일근로 후, 가산임금 **대신** 휴가 부여 |
| 부여량 | 1:1 (8시간 근무 → 1일) | 가산분 포함 (8시간 근무 → 12시간 = 1.5일) — 8시간 초과분은 100% 가산(제56조 ②) **확인 필요** |
| 요건 | 근로자대표와 서면합의, 사전 지정·통보 | 근로자대표와 서면합의 |
| 위험 | 사후에 1:1로만 쉬게 하면 휴일근로 가산수당(제56조 ②, 8시간 이내 50%) 미지급 문제 발생 가능 | — |

- 제55조 ①의 '휴일'은 주휴일과 공휴일(관공서 공휴일, 5인 이상 사업장 적용)을 말한다. 토요일이 무급휴무일로 정해져 있다면 토요일 근무는 '휴일근로'가 아닐 수 있다(취업규칙 정의에 따름). **확인 필요**
- 휴일대체의 사전 통보 시한에 관한 판례(대법원, 24시간 전 통보 취지로 알려짐)는 사건번호 **확인 필요**.
- **권장**: 근로자대표 서면합의서 작성 → 취업규칙에 '휴일근무 시 대체휴가 부여' 조항 반영 → 앱 배율 설정을 합의 내용과 일치시킴.

## 6. 시스템 구성

```
[직원 휴대폰 (PWA)] ──HTTPS──> [Caddy (자동 TLS 인증서)] ──> [gunicorn + Flask] ──> [SQLite 파일]
[관리자 PC 브라우저] ──HTTPS──┘                                                      └─ 일일 백업
```

- **HTTPS 필수**: 브라우저는 HTTPS에서만 GPS 위치를 제공함. 도메인(예: `hr.회사도메인`) 연결 + Caddy로 인증서 자동 발급.
- 서버 시간대와 무관하게 앱 내부는 **한국시간(KST)** 으로 기록.

### 서버 위치 대안 비교

| 대안 | 장점 | 단점 | 판단 |
|---|---|---|---|
| A. 국내 클라우드 소형 VM | 외부 현장에서도 접속, HTTPS 쉬움, 정전·회선 영향 없음 | 월 이용료 | **권장** |
| B. 사무실 PC / NAS | 추가 비용 낮음 | 포트포워딩·고정IP·인증서 관리 필요, PC 꺼지면 출근 불가 | 비권장 |
| C. 시프티 계속 사용 | 유지보수 부담 없음 | 인원 비례 구독료, 커스터마이징 불가 | 비교 기준 |
