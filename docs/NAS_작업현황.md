## 3. 주의 사항 (해제 전까지 유지)

1. **groupk3 `설계사업부-프로젝트`의 Network Trashes Folder**: 사용자가 C안(전체 삭제)을 정했으나, 같은 이름의 휴지통 폴더(`건설사업관리부/Network Trashes Folder`)에서 **2026년 작성 정비사업 조합설립 서류**가 발견되어 삭제를 보류하도록 요청함. 이미 삭제했다면 그 공유폴더의 휴지통(@Recycle)과 스냅샷은 비우지 말 것. **삭제 여부 미확인.**
2. **`건설사업관리부/Network Trashes Folder`**: 손대지 말 것. 1-5 대조 결과로 판단.
3. **GroupK**: 디스크를 많이 읽는 작업(`cleanup`, `--hash`)을 피할 것. `compare`(목록·크기만 읽음)는 가능.
4. 삭제는 항상 계획서 → 미리보기 → 실행 순서로. 휴지통·스냅샷 정리는 확인 기간 뒤.

## 4. 결정 사항

| 항목 | 결정 |
|---|---|
| NAS 역할 | 판단 위임 → 운영 / 보관 / 백업 분리 권장. GroupK는 운영 후보에서 제외 |
| 폴더 체계 | 사업부 → 연도 → 프로젝트 → 표준 하위폴더 |
| 전략·전력사업본부 | `03_사업개발`로 통합 |
| 다른 사업부 자료 열람 | 읽기 허용 |
| 정비·안전진단·인테리어 자료 위치 | 사용자 모름 → 검색 결과 정비사업 자료가 휴지통 폴더 안에서 발견됨 |
